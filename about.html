Instructions for Designing Your Own Impossible Objects

An impossible object (also called an impossible cylinder or an ambiguous cylinder) is a 3D shape that looks like one object from the front and a completely different one from the back — a circle and a square, a heart and an infinity symbol, and so on. Pick any two shapes, preview the result, and export a file to 3D print at home.

1Design your impossible object in the browser

Open the Designer and choose a front-view shape and a back-view shape from the dropdowns, or upload your own .svg files (see step 2). The 3D preview updates live and can be rotated. Adjust the orientation, width, height, and wall thickness sliders until you're happy with it.

2Design your own .svg shape (optional)

If the built-in shapes don't cover it, upload your own .svg for either view. The curve just needs to follow a couple of rules:

  • It must be a single closed curve, like the sample shapes in the Designer.
  • Every vertical line must cross it at exactly one or two points — no horizontal indentations. (It doesn't need to be convex.) Equivalently, the curve must be bounded above and below by the graphs of two functions of x. Any indentations that violate this will be ignored.
  • Size doesn't matter — shapes are scaled automatically to match.

Any vector drawing program works, or a graphing tool like GeoGebra if you'd rather define it mathematically — just export as .svg.

3Export to OpenSCAD

Click Export the File to download a self-contained .scad file with your dimensions prepopulated. Parameters can still be edited afterward, either in the file or via OpenSCAD's Customizer panel (Window → Customizer).

The optional legs are worth including — they let the model stand upright at the proper viewing angle. Two feet are round and one is a fish eye; the fish-eye foot should point directly toward or away from the viewer.

4Render and export an STL

If you don't already have OpenSCAD, the free, open-source program that turns the .scad file into a solid 3D model, install it from openscad.org/downloads.html.

  1. Open the .scad file in OpenSCAD.
  2. Design → Preview to preview the model.
  3. Design → Render for a full-resolution render.
  4. File → Export → Export as STL to save the .stl file.

5Print it

Send the .stl to your slicer (PrusaSlicer, Bambu Studio, Cura, etc.) and print as usual.

Printing advice

  • These shapes touch the build plate at only a few small points, legs or not — supports are essential.
  • A brim helps keep the object anchored to the plate.
  • Slowing the print speed can improve adhesion and reduce the chance of shifting or failure.

6Viewing the object

A few ways to see both silhouettes:

  • Look down on the object from about 45° to see the front-view silhouette; view from the opposite side at the same angle for the back-view silhouette.
  • Prop a mirror behind it — the reflection shows the back-side view. Tip the mirror a few degrees toward you (about 87° rather than a full 90°) for the best effect.
  • Shine a light down on it from behind at 45° to cast the "opposite shadow" — a shadow in the shape of the back-view silhouette.
