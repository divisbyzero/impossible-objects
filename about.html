Instructions for Designing Your Own Impossible Objects

An impossible object (also called an impossible cylinder or an ambiguous cylinder) is a 3D shape that looks like one object when viewed from the front and a completely different one from the back—a circle and a square, a heart and an infinity symbol, and so on. This tool lets you pick any two shapes (or upload your own), preview the resulting impossible object, and export a file you can 3D print at home.

1Design your impossible object in the browser

Open the Designer. Choose a shape for the front view and a shape for the back view from the dropdown lists or upload your own .svg files. (See (2) for recommendations on designing your own shapes). The 3D preview updates live so you can see the object from both angles and can rotate the object before committing to the final design.

Adjust the orientation, width, height, and wall thickness sliders until you're happy with the design.

2Design your own .svg shape (optional)

If the built-in shapes don't include what you're looking for, you can upload your own .svg file for the front view, the back view, or both. The curve just needs to follow a few rules so the algorithm can make sense of it.

  • It must be a single closed curve, like the sample shapes shown in the Designer.
  • Every vertical line must cross the curve at exactly one or two points. The curve doesn't have to be convex, but it can't have any horizontal indentations—no shape where a vertical line would pass in and out of the curve more than twice. Any such indentations will be ignored.
  • Put another way: if the curve sat in the xy-plane, it would need to be bounded above and below by the graphs of two functions of x.
  • The shape can be any size in the .svg files. If the two shapes are different sizes, they are automatically scaled to be the same width.

You can create .svg files in most vector drawing programs. If you prefer a more mathematical approach, you can also use a graphing program like GeoGebra, then export it as an .svg.

3Export to OpenSCAD

Click Export the File. This downloads a self-contained .scad file with your chosen dimensions prepopulated.

The parameters in the exported file are editable afterward, either by editing the numbers at the top of the file or using OpenSCAD's built-in Customizer panel (Window → Customizer).

The optional legs are worth including. They are designed so the model can stand upright for the proper viewing angle. Two feet are round and one is shaped like a fish eye. This fish eye foot should point directly toward or directly away from the viewer.

4Install OpenSCAD

OpenSCAD is the free, open-source program that turns the exported .scad file into a solid 3D model. Download it for Windows, macOS, or Linux here.

openscad.org/downloads.html

5Render and export an STL

  1. Open the .scad file in OpenSCAD.
  2. Press the Preview or use the Design → Preview menu item to preview the model.
  3. Press the Render button or use the Design → Render menu item to do a full-resolution render.
  4. Press the STL button or use the File → Export → Export as STL menu item to save the .stl file.

6Print it

Send the .stl file to your slicer (e.g. PrusaSlicer, Bambu Studio, Cura) as you would any other model. Then print.

Printing advice

  • Whether or not your model has the optional legs described in step 2, these shapes tend to touch the build plate at only a few small points. It's essential to print with supports.
  • Adding a brim in your slicer can help keep the object anchored to the build plate.
  • Slowing down the print speed can improve adhesion and reduce the chance of the model shifting or failing.

7Viewing the object

Once you have a printed (or rendered) model, here's how to see both silhouettes:

  • Look down on the object from about a 45° angle to see the front-view silhouette, and from the opposite side at the same angle to see the back-view silhouette.
  • You can also view it with a mirror behind it — the reflection shows the back-side view. For the best effect, tip the mirror a few degrees toward you (about 87° from horizontal, rather than a full 90°).
  • Shining a light down on the object from behind at a 45° angle casts the "opposite shadow" — a shadow in the shape of the back-view silhouette.
